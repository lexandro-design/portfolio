# Как добавить кейс

1. Скопировать шаблон в папку с коротким именем проекта (латиница, строчные, без пробелов):

   ```sh
   cp -r _template cases/<slug>
   ```

2. Заполнить `cases/<slug>/README.md` по разделам: задача, моя роль, что сделано, стек, результат, галерея. Если данных пока нет — оставить «уточняется».

3. Положить картинки в `cases/<slug>/images/`:
   - `cover.jpg` — обложка;
   - `01.jpg`, `02.jpg`, … — экраны в порядке галереи.

   Рекомендуемая ширина — 1600–2400 px, формат JPG. Под каждой картинкой в README подписать, что на ней.

4. Удалить из галереи строки под картинки, которых нет, и `images/.gitkeep`, если папка уже не пустая.

5. Добавить строку в таблицу «Кейсы» в корневом [README.md](README.md).

6. При необходимости — добавить проект в блок «Избранные проекты» в профиле `lexandro-design/lexandro-design`.

7. Закоммитить:

   ```sh
   git add cases/<slug> README.md
   git commit -m "docs(cases): add <slug> case"
   ```
