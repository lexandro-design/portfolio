# Parfumeria.by

Интернет-магазин парфюмерии в Беларуси. Я сделал для него дизайн-систему, больше 450 экранов в Figma и новый фронтенд на Next.js. Код закрытый, поэтому здесь только дизайн и описание.

Сайт: [parfumeria.by](https://parfumeria.by)

## Исходная точка

Магазин работает на Aspro (1С-Битрикс), и Битрикс остаётся источником данных. Бэкенд остаётся прежним, а фронтенд я вынес в отдельное приложение на Next.js, которое берёт каталог из Aspro.

## Дизайн

Начал с дизайн-системы: цвета, типографика, библиотека компонентов. Потом на ней собирал экраны, всего их получилось больше 450, и каждый сделан на трёх брейкпоинтах. При таком объёме без общей системы было бы не обойтись.

## Фронтенд

Фронтенд написан на Next.js с App Router и TypeScript, стили на CSS Modules. Каталог подключён в headless-режиме: данные приходят из Aspro, а всё, что видит покупатель, рендерит Next.js.

Поиск понимает транслит и дописывает запрос по ходу ввода: набираешь «шанель» и получаешь Chanel. Ещё сделал корзину и вход по SMS.

**Стек:** Figma, Next.js (App Router), TypeScript, CSS Modules, 1С-Битрикс (Aspro).
