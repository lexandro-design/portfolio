## Задача

Спроектировать интерфейс интернет-магазина на единой дизайн-системе и перенести сайт с Aspro (1С-Битрикс) на современный фронтенд-стек, сохранив каталог в Битриксе.

## Моя роль

Дизайн интерфейсов и фронтенд-разработка:

- дизайн-система и библиотека компонентов в Figma;
- макеты страниц и сценариев на трёх брейкпоинтах;
- вёрстка и разработка клиентской части на Next.js.

## Что сделано

**Дизайн**

- Дизайн-система в Figma: токены, типографика, сетка, библиотека компонентов.
- Более 450 экранов на трёх брейкпоинтах.
- Ключевые сценарии магазина: каталог, карточка товара, корзина, оформление заказа. <!-- проверить и дополнить список -->

**Разработка**

- Перенос сайта на Next.js + TypeScript.
- Стилизация на CSS Modules по токенам дизайн-системы.
- Каталог получает данные из Aspro/Битрикс. <!-- уточнить способ интеграции: REST, выгрузка, прокси -->

## Стек

- Figma — дизайн-система, библиотека компонентов, макеты
- Next.js — фронтенд
- TypeScript — типизация клиентского кода
- CSS Modules — стили компонентов
- Aspro / 1С-Битрикс — источник данных каталога
