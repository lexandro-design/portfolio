# MiMiMi AI

Мой собственный продукт: Telegram-бот для AI-фотосессий.

## Как это работает

Листаешь карусель готовых кадров по категориям (путешествия, студия и другие) и жмёшь «Сгенерировать этот кадр» или «Сгенерировать всю фотосессию».

Чтобы на кадрах было твоё лицо, сначала создаёшь цифрового двойника: задаёшь имя, загружаешь от 10 до 20 своих фото (бот проверяет, сколько их) и выбираешь параметры внешности. Дальше все генерации идут с твоим лицом.

Моделей несколько, можно выбрать: GPT-Image, Nano Banana Pro или Nano Banana 2. Есть отдельные режимы: генерация по референсам из Pinterest, фильтры, макияж и причёски, а ещё «режим бога» с расширенными настройками.

## Что внутри

Я разработал серверную логику бота и оркестрацию генераций, интегрировал API генеративных моделей и оплату через YooKassa. Модель freemium. Данные и файлы хранятся в Supabase: промпты по категориям лежат в PostgreSQL, фото для каруселей в Storage.

Весь контент живёт в базе. Пресеты, тексты, кнопки и картинки редактируются в Supabase без правки кода. Поэтому бота можно перенастроить под другую нишу, и разработчик для этого не нужен.

**Стек:** Supabase (PostgreSQL, Storage), Telegram Bot API, YooKassa, API генеративных моделей.
