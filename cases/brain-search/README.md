## Задача

Искать по собственной базе знаний по смыслу, а не только по совпадению слов, и отдавать найденное AI-агенту прямо в рабочем процессе. Индексация и поиск выполняются на своей машине.

## Что сделано

- MCP-сервер, который Claude Code вызывает как инструмент поиска.
- Индексация базы знаний: эмбеддинги считаются локально через Ollama.
- Гибридный поиск: векторный поиск по эмбеддингам вместе с полнотекстовым.
- RAG: найденные фрагменты передаются модели как контекст.
