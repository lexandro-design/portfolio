# Jarvis

Мой личный ассистент в Telegram, работает на моём сервере. Понимает текст и голос: голосовые распознаёт Whisper, отвечает GPT.

Я разработал серверную логику, подключил OpenAI API и сделал планировщик. Напоминания и задачи ставятся по расписанию через cron, и московское время пересчитывается в UTC. Память ассистента и задачи хранятся в моей схеме БД на PostgreSQL (Supabase).

Проект личный, сейчас его развитие на паузе.

**Стек:** OpenAI API (GPT, Whisper), Supabase, Telegram Bot API.
