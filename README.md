## Работа в ТИТАН-2

АО «Концерн ТИТАН-2» строит АЭС в Турции, Венгрии, Египте и Бангладеш как EPC-подрядчик Росатома. Я проектирую интерфейсы внутренних цифровых продуктов и довожу их от ТЗ до прототипа, который можно отдавать в разработку.

Сборку макетов в Figma я автоматизирую своими скриптами на Figma Plugin API (JavaScript). Они собирают экраны из библиотек компонентов, раскладывают канвас и привязывают стили, а при повторном запуске пересобирают экран без дублей.
