# LEXANDRO — портфолио

Алексей Свешников. Дизайнер интерфейсов и разработчик автоматизаций. Санкт-Петербург, работаю на фрилансе.

Проектирую интерфейсы и дизайн-системы в Figma, собираю автоматизации и AI-агентов на n8n и Supabase, верстаю и разрабатываю фронтенд на React и Next.js.

## Навыки

**Дизайн интерфейсов**

- Figma: макеты, прототипы, адаптив под несколько брейкпоинтов
- Дизайн-системы: токены, типографика, сетки
- Библиотеки компонентов

**Автоматизация и AI**

- n8n: сценарии и интеграции
- Supabase / PostgreSQL
- Telegram Bot API
- RAG: поиск по базе знаний для LLM
- AI-агенты

**Фронтенд**

- React
- TypeScript
- Next.js
- CSS Modules
